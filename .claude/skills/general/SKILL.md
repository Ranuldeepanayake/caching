## Objective

Help maintain consistentcy and follow best practices when coding.

## Workflow

1. Before starting work on a project, ensure that you have a clear understanding of the project requirements and objectives. 
2. When working with project using any programming language, adhere to the industry-standard project structure and naming conventions.
3. Create clear and concise documentation for the project, including README files, code comments, and usage instructions.
4. For any changes made to the codebase, ensure that they are well-tested and do not introduce any regressions or bugs.
5. README must be updated to reflect any changes made to the project, including new features, bug fixes, and usage instructions.
6. Ensure that the code is well-organized, modular, and follows best practices for the chosen programming language.
7. Create gitignore files to exclude unnecessary files and directories from version control.
8. Create dockerignore files to exclude unnecessary files and directories from Docker builds if a dockerfile is present in the project.


## Validation

- If host operating system is Windows, use the appropriate command for your shell (e.g., PowerShell, Command Prompt).
- If the host operating system is Linux or macOS, use the appropriate command for your shell (e.g., Bash, Zsh).

## Git guidelines

- Track all files not excluded by `.gitignore`.
- Do not commit without explicit instructions from the user.
- If the user instructs to commit, use descriptive commit messages that explain the purpose of changes.
